# Fourth GSPO 奖励设计与依据

当前评分版本：`fourth_boundary_v2`。目标是保住全文 CER，改善切换处文字和发言段的对应关系；有详细可信时间戳时才提供有限确认宽限。当前数据路径为“末尾无标点保留，有标点则检查最后 end 距音频结尾严格大于 1 秒”，随后以 keep + tail-only 准备新任务。不追求固定 WAIT 比例，也不处罚所有短输出。改变奖励/数据策略后从 Fourth SFT 开新 run，不冒充旧实验的精确续训。

完整参考由 `messages.assistant.content` 提取，语种与说话人标签仅供评分侧解析；旧 output/tags 的动作不作为 RL 答案，旧 WAIT 段的正文不会消失。tail-only 不重建或校验全部中间分段，时间戳只用于末尾过滤，任务 `alignment=[]`，不提供 switches 时间条目。因此本模式可优化正文、局部语种、换人和标点，但没有逐词/切换延迟监督。下面时间项的公式仅在显式 aligned 数据提供可信端点时生效。

这版使用 Fourth 的 DIRECT / WAIT / SPK_CHANGE 协议；不预测语种标签和持久说话人编号。语言和说话人的真实标签留在评分侧，不能送给 actor。框架保持原 FLEX-GSPO 的序列重要性比率和 KL 约束，不把局部统计冒充局部 token advantage。

## 2. 可执行评分

先检查完整因果轨迹。非法输出、被 token 上限截断、错误结束格式奖励为 -3。`annotation_end` 在最后一个有效音频块后结束；`eof` 才追加结束事件并要求 WAIT。

正文移除动作和换人 token 后拼接，不把每轮提交当一句话。定义：

```text
Q = 1 - min(2, normalized_CER)
R0 = Q
     - 0.40 × 切换首部平均词/字符错误率（截断到 2）
     - 0.20 × 短切换段全删比例
     - 语言内容惩罚
     - 换人边界惩罚
     - 标点惩罚
     - 有界额外等待惩罚
     - 0.10 × 可核对的提前输出比例
```

CER 在全语种使用字符编辑距离，不再把英文整词错误率当成 CER。NFKC、大小写和 Unicode 数字做一致归一化；不去音调、不翻译、不把口语数字改写为另一份文本。普通空白和句法标点不参与 CER，数字内部小数点、分隔符及邻接数字的正负号/百分号保留，避免 `3.50` 和 `350`、`50%` 和 `50` 被视为完全相同。标点另计。

实现优先使用已安装的 RapidFuzz；未安装时使用同定义的 Python 编辑距离，结果一致但较慢。可在原虚拟环境安装 `python3 -m pip install rapidfuzz`，不需要更换 Swift/CUDA 环境。

### 语言切换

语言内容惩罚为 `0.90 × max(局部原词错误, 局部切换CER代价, 异文字证据代价)`。局部切换 CER 在每个新语种区间计算，代价使用区间误差上限 1 的“最差值与均值的平均”。避免一小段法语被很长的正确中文稀释。保留原有首部和短段漏转录评分。

不设置“输出了新标签就得分”。法语译成中文、漏掉法语、在法语处填无关英文都按参考原文扣分。共享词、借词和人名按实际参考判定，不因为它长得像外语就扣分。书写系统只能辅助，不能提供准确的声学语种判断。

### 换人

原始标签提取真实换人边界；模型的 SPK_CHANGE 对齐到正文位置，保留正确、遗漏、额外标记统计。增加局部归属严重程度，避免“晚一个字”和“晚三个字”永远同分：

```text
边界错误 B = min(1, (漏报+误报)/max(1,真实变化数,预测变化数))
局部成本：边界偏移字符占相邻发言段比例，与新发言段删除比例取 max
归属错误 A = 0.5 × (局部成本最大值 + 局部成本均值)
换人惩罚 = 0.40 B + 0.40 A
```

精确位置作为锚点，在锚点之间按顺序、字符距离配对其他边界。晚移按新发言段长度归一化，早移按前一段长度归一化，上限 1；漏换人记局部成本 1。多余段内边界也计入局部损伤；空首尾/重复标记扣边界分但不据此推断全局身份。没有固定三词的偏移搜索范围。使用去标点后规范化字符质量，不能将统计称为标准 SA-WER。

- 参考 `好的。<换人>我知道这个问题。`，候选把“我”或“我知道”放到前段，即使全文 CER=0，也按不同受损文字量扣分。
- 删除新人的开头仍计删除成本，不能以漏字逃避归属判断。
- 一个漏标不机械翻转后面所有人；后续正确边界恢复局部归属。
- 删除造成边界位置不确定时保留可对齐区间，并记录 `speaker_ambiguous_changes`，不伪造精确身份。
- 正文字词正确但位于错误一侧，不进入“正确提交延迟”的成功样本；同时报告计时覆盖，不能通过删掉慢内容得到漂亮的延迟图。

同人换语言不能凭空加换人标记。同语种换人必须标记。同轮可以同时提交前人句尾和新人开头。无可靠 speaker 标注的记录不计算此项。

该协议只区分“变化”，不能证明 A-B-A 里的第三个人就是 A；没有持久编号就没有身份归属监督。也不报告 DER 或冒充说话人分离指标。

### 句号和短碎句

依据整条拼接正文的词/字符对齐检查边界，绝不根据 DIRECT 长度直接罚分。

- 参考连续，候选无故插入句号、问号或感叹号：扣分，包括参考完全没有句末句号时。不能把错误句号替换成问号绕过判断。
- 无根据的句号制造了 1～5 个字母/数字的短片段：再加小额罚分。
- 参考“好。你说。”：保留真实短句，不处罚。
- 正确句号后同轮带下一句开头：不处罚。只因末尾有两三个字就罚，会鼓励延迟。
- 小数、常见缩写、网址、省略号和不确定换行做豁免；词对齐不够可靠的位置不强判。
- `punctuation_trusted:false` 可关闭该记录的标点监督；默认信任参考。这个开关不能修复原始标点，需要改善参考。
- 截取末尾只屏蔽尾部的结束标点要求，句内标点仍评分，不把整条样本全部放弃。
- 完整参考末尾有标点，但对应最后 DIRECT 没标点、按新规则保留的记录，通过 `terminal_punctuation_trusted:false` 只屏蔽末尾标点要求。参考正文不修改，句内标点保持监督。

设多余句子终止符 E，造成短片段的多余终止符 S，可信句末漏标 M/可信句末数 B，参考规范化字符数 N：

```text
标点原始成本 P = 0.60 E/(2+E) + 0.10 S/(1+S) + 0.12 M/max(1,B)
标点惩罚 = min(0.10, 0.25/max(1,N)) × min(1,P)
```

此处上限是本项目防奖励绕过的适配：旧版 `我知道。你有问题` 会比 `我知倒。你有问题` 分数低，因为错字破坏了标点的精确对齐锚点。现在标点和等待辅助扣分合计小于一个字符的 CER 成本，不鼓励通过错字/删字隐藏标点。这个保证限定其他奖励项相同；语言/归属仍是独立的任务正确性目标。较长录音的标点梯度会较弱，这是保住现有 SFT 正文质量的取舍。

### 时间和质量优先

当前默认 `--timing-mode tail-only` 的 `timed_units=0`、`latency_penalty=0`；`--switch-grace-turns 1` 不为它创造时间信息。需要直接训练等待成本时，应另行使用 `--timing-mode aligned` 与完整可信对齐。保留 quality_latency 入口仅为统一训练流程，不能据此声称这批 tail-only 数据已经优化了实时延迟。

有可信词/字符 end 才计算其最早覆盖音频轮，以及实际提交又多等多久。只有语种切换起点不能知道词何时结束，不伪造 end。粗语义单元只能锚定外侧端点，不给中间字符均分时间。

```text
g = max(0, 1-CER) × (1-max(局部原词错误,局部切换CER代价,换人边界错误,局部归属错误))
latency_penalty = min(0.10, 0.5/max(1,参考字符数)) × g × timing_cost
```

`--switch-grace-turns 1` 是评分器参数，默认在真实语种/说话人变化处给一个额外输入轮的确认宽限。设首部可信完成时间最早被第 k 块覆盖，宽限截止为第 k+1 块末。首部沿用前三个词/字符单元；若只有从该边界开始的完整语义单元 end，则仅使用该单元真实完成端点，绝不均分内部时间。跨越下一变化的粗单元不能作为这个边界的确认锚点。

同一个新发言/语种区间的待提交文字共用一个固定截止时间，直到下一个真实变化；不会每个词各自重新获得一轮宽限。晚于该截止时间才说完的词仍按自身最早可提交轮评分。末尾不足整轮时使用真实末块结束时间，不虚构额外音频或 EOF。`--switch-grace-turns 0` 可作无宽限对照；训练和 evaluate 使用同值。

`timing_cost` 对每个可评分单元使用 `超出宽限的等待秒/(4+超出宽限的等待秒)`；遗漏、提前猜出及归错段的计时单元按最大成本计。原始等待时间另外保留在 `extra_wait_ms_histogram`，宽限后的时间在 `excess_wait_ms_histogram`。`switch_extra_wait_ms_histogram` 覆盖语种及说话人变化首部，含可用粗单元完成端点；不是只统计语种变化，也不是完整说话人起声延迟。

最大时延扣分仍小于该记录一个字符错误的 CER 成本。整体正确、仅比较速度时仍能区分，但长录音上的这个时延信号较弱，这是“正确优先”的保守取舍，不代表解决了所有长 WAIT。

宽限不意味着强制 WAIT，也不加在普通位置。一个候选可以同轮输出前人的句尾和换人后的开头；也可以先交前人句尾、下一轮再交新人完整开头。两者在正确且处于宽限内时都可满分。时间戳、边界和参考均仅在评分侧，actor 不提前看到下一轮音频。

提前输出只对有可信 onset 的位置核对；强制对齐的 end 不是唯一正确的识别时刻，不强制每个正确词必须等到某个机械时刻才能得分。SFT 的单元完成规则和 RL 的时间偏好应分别理解。

无精确词匹配且 CER≥0.5 的低覆盖输出使用单独的低分区间，避免随机共享字母产生好分；小拼写错误仍按 CER 渐进评分。极低质量的有限输出使用单调压缩保留排序；完全 WAIT 在有正文样本上为 -2.5，静音参考正确 WAIT 为 1。最终边界行为见测试，不能只根据展开公式推导极端分数。

## 3. 观察效果

保留 500/1000/1500/2000 步，训练到 2500 时也保留 2500，不自动删除早期版本。用已有独立测试集比较原 SFT 和各 checkpoint；用户给的文件全作训练，不自动拆验证集。

TensorBoard 包含总 reward、组内奖励相同比例、CER、语言/换人/归属/标点/时延罚分及归错字符数。`rewards/rollouts-*.jsonl` 记录每条完整候选、`reward_version`、宽限参数和分项；`metrics-*.json` 是小型累计计数快照，不保存波形。`evaluate.py` 除已有数据桶外，分别汇总 `boundary/language_only`、`boundary/speaker_only`、`boundary/both`、`boundary/none`；不改变原始采样。

评测一起看全文 CER、归错字符和换人漏/误报、切换漏段、不受支持的断句。aligned 评测才进一步看正确提交延迟 P50/P95 与计时覆盖；tail-only 的时间未知不能解释为零延迟。某组没有样本就不输出该组。时延百分位只统计拼写正确且未检测到归属错误的可计时单元，必须同时看删除和覆盖。

本地测试验证评分排序、调度和导出契约；不代替四卡/八卡 GPU 的端到端训练或真实会议识别评测。
