# 方法与验证边界

OmniCommit 研究多语言、说话人归属和提交时机的联合流式转录。协议动作只有 `<|DIRECT|>`、`<|WAIT|>`，沿用 FLEX 的动作 token 拼写；不引入 FLEX 翻译重组动作。

## 从完整音频到稳定前缀

同一个教师独立识别完整音频，以及从录音开头到各截点的累计音频。教师调用不接收完整参考转录，也不强制继承上一次识别文本。输入 JSONL 的参考只用于离线检查，不能进入截断音频的识别 prompt。

记完整识别为 F，历史截断识别为 H_j。在时刻 t，只考虑 j<=t 且 **整个 H_j 都是 F 前缀** 的候选，选择最长者；没有候选则为空。不能截取一个错误完整假设的正确开头冒充同一算法。前缀比较同时考虑每个字符的语言和说话人属性，并规范化相邻同属性段的分段差异。

相邻累计稳定结果的差分成为本轮输出：非空为 DIRECT，空为 WAIT。每个非空段写完整 `<language><speaker>` 头；同一说话人在同一会话内使用相同编号。保留尾部静音，因此最后一轮可以 WAIT。全部 WAIT 的会话没有转录监督，不能当作成功 ASR 样本。

`normalized` 数字策略额外保护完整教师结果中的连续数字串（含常见小数、日期分隔符和百分号）：若候选提交边界落在串内部，将边界退到该串起点。例如最终文本是 `100000000` 时，不因较早预测 `100` 恰好匹配字符前缀而提交 `100`。这是离线标签构建的规则，不涵盖所有自然语言数量表达，也不是推理时可以访问最终文本的机制。可选 `--holdback-chars` 也只作用于离线提交标签；模型需要从这种监督中学习等待。

这是 [Confucius4-R2T2 §4.3–5.2](https://arxiv.org/html/2611.06043v1#S4.SS3) 的 whole-output final-anchored 思路的 **字符及归属属性扩展**。原论文以自身完整转录作锚；它的 SFT 目标是累计 LSP，必要时后接 Wait。本项目输出的是适配 FLEX 训练接口的多轮增量轨迹，并不声称复现原论文训练或 token 级数学定义。

## 不能从单调性推出的结论

- 标签单调不等于转录正确。教师完整音频输出可能错误，需结合参考审查。
- 与最终识别一致不等于当前声学信息充分。教师可能提前猜中；尤其需要专项审查数字、罕见人名、语言切换和说话人切换。
- 稳定的 speaker 编号不证明正确的身份归属。独立前缀调用中的说话人误聚类可能持续一致；不能按字符串相同就声称 diarization 已验证。
- 保留固定长度尾部是可选保守规则，不保证覆盖一个完整词、数值或实体。
- 只保留线性段落标签不能完整表达多人同时发声的时间关系。当前版本是序列化的 speaker-attributed ASR，并非有重叠时间监督的完整 diarization 系统。
- 不能用现有纯文本 dsv4 服务替代音频教师。接口必须实际接受音频数据，并具备所需语音能力。

## 音频可见性

教师得到的是累计音频前缀；SFT 的每个 user 轮得到的是一个新增音频区间。两者的输入组织不同。SFT 保留此前各轮上下文，通过原生因果文本注意力使用历史。

必须先在源采样率截出区间，再下混、重采样及提取特征。先对完整录音提取非因果特征再切块会泄漏后续声音。虚拟音频读取器继承 FLEX 的区间读取方式，每个音频块单独送入原生处理流程。音频编码器内部的分段隔离及真实模板编码仍应在目标 GPU 环境验收。

## 推荐评估

分别报告英文 WER、中文 CER、说话人归属错误、多语言切换错误、数字/时间/人名专项准确率，以及提交延迟。WAIT 比例只用于诊断，不设定所有场景通用的低 WAIT 配额。服务端 wall-clock 延迟与音频时间轴上的提交延迟分开统计。

当前发布范围是数据构建与 SFT。真实服务调用、GPU 优化器步骤、checkpoint 保存/加载以及上述质量指标，需要在目标模型服务和训练机器上验证。离线 replay 只能验证程序行为，不能证明教师质量或训练效果。
